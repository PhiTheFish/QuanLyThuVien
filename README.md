# QuanLyThuVien
Ứng dụng quản lý thư viện được xây dựng bằng **Java Swing** (Giao diện), kết nối cơ sở dữ liệu **SQL Server** thông qua **JDBC** theo chuẩn mô hình **DAO (Data Access Object)**.

Hướng dẫn sử dụng:
* Mở **SQL Server Management Studio (SSMS)**
* Sử dụng file `script.sql` để tạo database
